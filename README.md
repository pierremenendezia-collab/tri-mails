# Tri mails

Pages statiques publiées via GitHub Pages pour renseigner les champs de
branding OAuth de Google Cloud (page d'accueil, politique de confidentialité,
conditions d'utilisation).

- `index.html` — présentation de l'outil
- `confidentialite.html` — politique de confidentialité
- `conditions.html` — conditions d'utilisation

Ce dépôt est public : n'y commiter ni identifiants, ni jetons, ni code
contenant des secrets.
